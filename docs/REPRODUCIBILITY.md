# 复现协议与核验范围

## 固定版本

本仓库默认方案对应半决赛56.132，使用epoch47 EMA和原始G6。复赛58.903属于更早阶段，不与半决赛分数直接比较；旧实现仍可在Git历史中查阅。

固定结构为W424/D4/Q300/OPF1，880×1600。训练为2000张全量、64轮、seed42、双卡每卡batch4、累积1，使用HBS、RFS、RGB低照和全局0.5/IR0/Depth2蒸馏。模型完整保留原生5层decoder参数，选择第4层有效预测。

最终epoch47完成48轮，EMA更新15072次。全量运行没有独立验证集，最终checkpoint通过线上候选比较选择，因此线上成绩不能当作无偏独立验证结果。后续研究应另设按序列/场景分组的验证集并复核随机种子。

## 已完成核验

归档过程完成了以下检查，记录见[reproduction_check.json](reproduction_check.json)：

- 便携模型构建后，1110个EMA状态张量严格加载并逐一相等。
- 推理构建阶段只读取学生文件，没有读取教师或官方初始化权重。
- 使用该checkpoint身份绑定的1000张逐视图缓存复算原始G6，16286框、1000个TXT逐字节一致，差异0。
- 训练入口导入与参数帮助检查通过，没有启动重新训练。
- 本仓库把纯G6后处理与Torch视图加载分离；数值函数及视图预处理函数体与已核验归档版本保持一致，并增加CPU回归检查。

这些检查不等同于在任意新环境重跑完整GPU预测，也不证明不同硬件、依赖版本或重新训练后分数完全相同。发布整理期间没有重启GPU训练或完整GPU预测。

## 推理协议

FP32整图＋四切片，切片重叠0.2。每视图880×1600、top300候选，内部切片边缘1.5像素截断过滤；同类IoU0.6一对一合并，分数加权坐标、最大分数。仅切片支持的簇按0.25+(s−0.25)×0.5降分。最后score≥0.25、全图max100、5位小数。

本版本无水平翻转、C1、额外高分辨率、IR局部采样或不同模型融合。测试集图像没有用于训练、伪标签或自监督适配。

## 内容校验

[reference_results.json](reference_results.json)记录原始提交身份和TXT内容聚合哈希。内容哈希按文件名排序，依次加入文件名UTF-8、NUL、原始TXT字节、NUL；避免ZIP容器元数据影响比较。

```bash
python tools/check_artifacts.py --checkpoint weights/student_epoch47_ema.pt
python tools/check_artifacts.py --submission outputs/phase3/submission_epoch47_g6_conf025.zip --exact
```

训练图像与标签必须匹配原协议。网盘提供的2000份标签与最高分运行聚合SHA256一致：`6ab79c5777b6f28de555230ff42d0db8ff31e9772643cb4112b68db7eeb29378`。教师和学生均只使用官方训练图像。
